# 家庭打卡小程序 0.3.1 版本说明

**版本号：** v0.3.1
**发布日期：** 2026-09-07
**上一版本：** v0.3.0

---

## 版本概述

0.3.1 版本是**数据可靠性与一致性强化版本**。针对 0.3.0 云端化后暴露的问题，完成云端数据自动恢复、账号绑定数据合并、头像云存储化与统一渲染组件、表单交互一致性四大块改造。

## 一、新增功能

1. **云端数据自动恢复**：退出登录/切换账号清缓存后，重新登录自动从云端拉回个人档案与家庭成员数据，按登录账号隔离
2. **头像云存储化**：微信/相册头像保存时自动上传 uniCloud 云存储（永久 fileID），跨设备、清缓存后仍可显示
3. **统一头像组件**：新增 avatar-image 组件，cloud:// fileID 自动解析临时 URL（带缓存），加载失败自动兜底默认头像；替换全部 4 处头像显示
4. **绑定账号数据合并**：绑定虚拟成员后自动合并重复记录，字段合并保留完整档案，修正成员计数
5. **表单必填规范**：性别/家庭关系首次填写默认空，姓名/性别/家庭关系必填校验
6. **家庭名称云端持久化**：修改后保存云端，换设备保持

## 二、Bug 修复（共 12 项）

- **数据与账号（5）**：清缓存后数据丢失（云端恢复缺失）、切换账号数据未隔离、绑定报"姓名不能为空"、绑定后成员重复、绑定后档案丢失
- **头像（4）**：清缓存后头像全空、头像渲染层加载报错、cloud:// 渲染失败 500、保存头像报"颜色不合法"
- **UI 与表单（3）**：绑定选择器文字不居中、占位字体不一致（三轮修复最终用 placeholder-style 内联解决）、家庭名称修改不保存

## 三、优化改进

1. 全部 input 占位改用 placeholder-style 内联样式，两页占位文本 28rpx 完全统一
2. 云端恢复带 20 秒防抖，避免频繁请求
3. 成员云函数 update 改为部分更新字段级校验，更符合绑定/局部更新场景

## 四、已知限制

1. 业务模块（饮食/运动/学习/食谱/出行/账本）仍为 localStorage 实现，未迁移云端
2. 支付宝云免费版 2026-10-04 到期，需关注续期
3. 体验版需在微信公众平台配置合法域名（request/uploadFile/downloadFile 三个）后才能真机访问云端
