# 家庭打卡小程序 0.3.0 版本说明

**版本号：** v0.3.0
**发布日期：** 2026-09-06
**上一版本：** v0.2.0

---

## 版本概述

0.3.0 版本是家庭打卡小程序从纯前端本地存储向服务端存储迁移的里程碑版本。核心完成了 uniCloud 后端接入、完整登录体系、家庭空间与成员账号绑定闭环，同时对「我的」页面进行了全面整改和体验优化。

---

## 一、新增功能

### 1. uniCloud 服务端存储
- 接入支付宝云 uniCloud，数据从 localStorage 迁移到云端数据库
- 支持多设备、多成员联网使用

### 2. 完整登录体系
- 微信授权登录
- 手机号 + 密码登录/注册（手机号作为唯一账号标识，密码加密存储）
- 登录态自动管理与启动拦截

### 3. 家庭空间
- 家庭创建与邀请码加入
- 家庭名称编辑
- 家庭管理员/成员角色区分与权限控制

### 4. 家庭成员账号绑定
- 登录用户自动关联家庭成员
- 虚拟成员通过预设手机号或绑定码关联登录账号
- 成员详情页展示完整档案与绑定状态

### 5. 「我的」页面卡片化
- 头像 + 姓名 + 角色标签 + 脱敏手机号 + 身体数据合并为头部卡片
- 个人信息档案支持手机号、家庭关系、出生日期等完整字段
- 头像支持微信头像授权与相册上传

---

## 二、Bug 修复（共 20 项）

### 编译与环境（4项）
- pages.json 编码修复、uniCloud SDK 打包、服务空间配置、依赖安装

### 登录与注册（4项）
- 手机号注册支持、注册后可登录、关闭图形验证码、登录后页面栈清理

### 家庭与成员（4项）
- 云函数返回格式对齐、成员详情返回按钮、绑定码生成修复、保存头像缺少字段

### UI 与交互（6项）
- 按钮文字居中、头像遮挡修复、关系字段回显、相机图标位置、绑定选择器居中、账号数据隔离

### 数据校验（2项）
- 手机号 4-12 位数字校验、出生日期手动输入+选择器双模式

---

## 三、优化改进（共 10 项）

1. 「我的」页面去掉冗余标题文本
2. 头像支持微信头像/相册双选择方式
3. 出生日期改为年/月/日三列独立输入
4. 个人信息档案增加家庭关系字段
5. 成员编辑表单增加性别、身高、体重、出生日期
6. 个人信息卡片数据项增加竖线分隔
7. 添加成员按钮改为实线边框
8. 家庭名称支持编辑
9. 成员表单字段顺序与个人档案统一
10. 成员头像编辑逻辑与个人档案统一

---

## 四、已知限制

1. 现有业务模块（饮食/运动/学习/食谱/出行/账本）仍为 localStorage 实现，尚未迁移到云端
2. 家庭名称修改仅保存在本地，未同步到云端数据库
3. 支付宝云免费版 2026-10-04 到期，需关注续期
4. 成员详情页个人档案数据来自本地存储，后续需支持每位成员独立云端档案

---

## 五、升级建议

- 升级前请确保已在 HBuilderX 中上传最新云函数（family、member、register）和公共模块
- 微信开发者工具中清除缓存后重新登录，避免旧 token 影响
- 首次使用需注册账号并创建家庭空间
