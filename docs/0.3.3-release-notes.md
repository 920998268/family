## 版本概述

0.3.3 是**学习打卡上云版本（M2-B）**。

上一版 0.3.2 把饮食、运动打卡迁到了 uniCloud，但**学习打卡仍留在本地**——
按产品定义「打卡中心 = 运动 / 饮食 / 学习三大打卡模块」，这等于「打卡上云」只做了一半。
本版把学习打卡补齐，M2（打卡模块）至此整体收口。

学习是**主从结构**（打卡从属于计划），因此本期也是首次引入级联删除：
删除学习计划时，服务端会连带清理该计划的全部历史打卡。

## 一、新增功能

### 1. 学习计划上云

学习计划与学习打卡各建一个集合，由同一个 `study` 云函数托管
（两者是主从关系，且删计划要级联删打卡，拆开会造成跨函数写或孤儿记录）。

- 计划：标题 / 学习内容 / 打卡频率 / 目标次数 / 归属成员；
- 打卡：计划 / 日期 / 备注 / 打卡成员。

### 2. 级联删除：删计划自动清理其全部打卡

服务端分批次删除该计划的历史打卡，**没删完就不删计划**并返回可重试的失败
——带着没删完的打卡删掉计划，会留下永远找不到归属的孤儿打卡。

### 3. 「同一计划同一天只打卡一次」下沉到数据库层

这是本期上云相对纯本地方案的**实质收益**：

- 本地只能靠应用层校验，两台设备同时点击会重复；
- 云端用唯一索引 `familyId + planId + date` 兜底，并发也只会保留一条。

### 4. 学习打卡的离线同步

与饮食 / 运动不同，学习计划**不分日期**（全量列表），只有打卡按日期组织，
所以同步层为学习开了**两条拉取通路**：`pullStudyPlans()` 全量 + `pullStudyCheckins(date)` 按日期。

断网时正常打卡（本地即时生效），恢复网络后自动补传。

## 二、Bug 修复（共 1 项）

### 1. 表单缺少长度上限，超长内容会静默丢失

云函数对字符串字段有长度上限，而**前端表单完全没有 `maxlength`**。
后果是最隐蔽的一类数据丢失：

> 输入超长内容 → 本地写入成功（界面一切正常）→ 推云端被拒 →
> 重试 5 次后丢弃待同步标记 → **数据永久只在本地，全程不报错**。

该隐患从 0.3.2（饮食 / 运动）就已存在，本版连同学习一并修掉，
并加了「前端上限 == 云端上限」的一致性测试防止再次漂移。

## 三、优化改进

1. **建索引说明写细**：补充入口路径、5 条索引的完整填写参数（索引名 / 字段排序 /
   是否唯一），以及三个易错点（复合索引字段顺序不可颠倒、建唯一索引前不能有重复值、
   索引即时生效无需重传云函数）。
2. **文档一致性守卫扩展**：新增 12 项断言，把本期的方案文档与部署清单纳入守卫，
   并把「复合索引字段顺序」也纳入自动检查。
3. **表单换算原语**：新增 ISO ↔ 毫秒的双向容错换算，以及 `note` 归一化
   （云端返回 `null` 时必须转成空串，否则整条打卡会被前端校验判非法而静默丢弃）。

## 四、已知限制

1. **跨设备删除不同步**（A 删掉记录后，B 刷新仍看得到）
   —— 已在后续 **0.3.4** 中通过「删除日志（墓碑）」整改。
2. **历史老数据未批量上云**：M2 之前存在本地的记录不会自动导入云端，
   按路线图留在 M4 做统一的「本地数据导入云端」入口。
3. **学习统计未做**：完成率、连续天数、周报等仍待规划。
4. **一人多家庭 / 家庭解散**不支持（MVP 范围外）。
5. 支付宝云免费版 **2026-10-04 到期**，到期前需续期或升级。

## 五、升级与发布说明

### 云端部署（HBuilderX，需手工操作）

本版**只需上传 4 项**：

| # | 上传项 |
|---|---|
| 1 | `uniCloud-alipay/database/study_plans.schema.json` |
| 2 | `uniCloud-alipay/database/study_checkins.schema.json` |
| 3 | 云函数 `uniCloud-alipay/cloudfunctions/study` |
| 4 | 5 条索引（含 3 条唯一索引） |

> 公共模块 `checkin-shared` **不需要重新上传**（本期未修改它）。
> ⛔ 请勿使用「上传所有云函数、公共模块及 actions」——
> 该操作会连带重传 `uni-config-center`，导致 uni-id 配置丢失、登录全部失败。

部署与真机验收的完整步骤见 `docs/0.3.3-m2b-deploy-checklist.md`（含 23 条验收用例）。

### 前端

```
npm run build:mp-weixin
```

> 前端构建与云侧上传是**两条独立通道**：改 `src/**` 只需重新构建，
> 改 `uniCloud-alipay/**` 才需要重新上传。
