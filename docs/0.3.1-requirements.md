# 家庭打卡小程序 0.3.1 版本需求文档

**版本号：** v0.3.1
**发布日期：** 2026-09-07
**上一版本：** v0.3.0

---

## 一、需求背景

0.3.0 完成云端存储迁移后，暴露出数据可靠性与一致性问题：退出登录清缓存后数据无法恢复、账号绑定后成员数据重复且档案丢失、头像跨设备失效、表单交互不一致。0.3.1 版本聚焦解决上述问题，提升数据可靠性与表单体验。

## 二、新增需求

### 1. 云端数据自动恢复机制
- **场景**：退出登录/切换账号清除本地缓存后，重新登录需恢复已保存数据
- **要求**：
  - 登录成功、应用启动、相关页面 onShow 时自动从云端拉取家庭成员列表与当前账号个人档案，写入本地缓存
  - 恢复按登录账号 userId 匹配，不同账号数据隔离
  - 20 秒防抖避免频繁请求
  - 云端数据不完整时跳过恢复，用户重新填写保存后云端自动补齐

### 2. 头像云存储化与统一头像组件
- **场景**：微信头像/相册头像需跨设备、清缓存后仍可显示
- **要求**：
  - 保存档案/成员时，本地临时头像路径（wxfile:// 等）自动上传 uniCloud 云存储，存永久 fileID
  - 新增统一头像组件（avatar-image）：cloud:// fileID 自动解析为临时 URL（getTempFileURL 带缓存），加载失败兜底显示默认头像（颜色块+首字）
  - 头像尺寸/背景色/占位内容可配置，替换「我的」「成员详情」「个人档案」「添加/编辑成员」全部头像显示

### 3. 绑定账号后成员数据合并
- **场景**：用户已有家庭（账号自动创建成员记录）再绑定管理员预设虚拟成员时，需合并为一条
- **要求**：
  - 绑定成功后云端自动合并同一账号的重复成员记录
  - **字段合并策略**：保留被绑定成员，将其他记录的非空字段（姓名/性别/家庭关系/生日/身高/体重/目标体重/头像/手机号）填补进保留记录，删除多余记录
  - 同步修正家庭 memberCount（绑定不再重复 +1，合并删除时扣减）
  - 前端绑定成功后强制从云端刷新本地成员与个人档案

### 4. 表单必填与默认值
- **要求**：
  - 首次填写个人信息档案与添加成员时，性别、家庭关系默认为空，显示占位提示「请选择性别/请选择家庭关系」，由填写人选择保存
  - 姓名、性别、家庭关系为必填项，未填写时保存被拦截并提示

### 5. 占位提示文本字体统一
- **场景**：性别/家庭关系选择器占位与姓名/身高/体重输入框占位字体大小不一致
- **要求**：
  - 两页（个人信息档案、添加成员）全部占位提示文本字号、颜色、比例完全一致（统一 28rpx、浅灰 #d6d3d1）
  - 使用 placeholder-style 内联样式，确保微信原生组件下必定生效

### 6. 家庭名称云端持久化
- **要求**：家庭名称编辑后保存到云端数据库，重新进入/换设备后保持修改结果

### 7. 账号绑定开放
- **要求**：家庭体系下所有成员均可选择绑定登录账号；绑定校验预设手机号与当前登录手机号一致性

---

## 三、非目标（本期不做）

1. 业务模块（饮食/运动/学习/食谱/出行/账本）仍为本地存储，云端迁移不在本期
2. 家庭管理员删除成员功能不在本期（仅可添加/编辑）
3. 服务端数据导出与备份工具不在本期

---

## 四、验收标准

1. 退出登录清缓存后重新登录，个人档案与成员数据自动恢复 ✓
2. A/B 账号数据互相隔离，B 登录不显示 A 数据 ✓
3. 绑定虚拟成员后成员列表仅一条记录且档案完整 ✓
4. 上传头像后清缓存重登，头像仍正常显示 ✓
5. 两个表单页全部占位文本字号颜色一致 ✓
6. 姓名/性别/家庭关系必填校验生效 ✓
