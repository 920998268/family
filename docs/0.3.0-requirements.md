# 0.3.0 版本需求与优化清单

## 一、后端架构迁移（核心需求）

### 1.1 uniCloud 服务端存储
- 从纯前端 localStorage 迁移到 uniCloud（支付宝云）服务端存储
- 创建服务空间 `familycheckinprogram`，支持云函数、云对象、云数据库
- 数据库集合：families、family_members、uni-id-users、opendb-verify-codes 等

### 1.2 云函数与云对象
- `family` 云函数：创建家庭、加入家庭、获取家庭状态、生成邀请码、成员管理、绑定码生成与绑定
- `member` 云函数：成员档案 CRUD
- `register` 云函数：自定义手机号注册（无需验证码）
- `uni-id-co` 云对象：uni-id 登录/注册/登出封装
- `uni-captcha-co` 云对象：验证码（已关闭登录验证码）

## 二、账号与登录体系

### 2.1 双模式登录
- 微信授权登录（获取微信头像、昵称）
- 手机号 + 密码登录（手机号作为唯一标识）
- 手机号 + 密码注册（密码 hmac-sha256 加密存储）

### 2.2 登录态管理
- token 自动管理（uni_id_token）
- 启动时登录拦截：未登录跳转登录页
- 退出登录功能

## 三、家庭空间

### 3.1 家庭创建与加入
- 首次登录无家庭 → 跳转家庭创建/加入页
- 创建家庭：输入家庭名称，自动成为管理员
- 加入家庭：输入邀请码加入
- 已有家庭 → 直接进入首页

### 3.2 家庭信息管理
- 家庭名称展示与编辑（管理员）
- 家庭邀请码生成、展示、复制
- 家庭角色标识（家庭管理员/家庭成员）

## 四、家庭成员管理

### 4.1 成员档案
- 成员增删改查（管理员可删除，普通成员可添加/编辑不可删除）
- 字段：姓名、性别、家庭关系（9种：爸爸/妈妈/爷爷/奶奶/外公/外婆/儿子/女儿/其他）、手机号、出生日期、身高、当前体重、目标体重、头像
- 头像支持：微信头像授权、相册上传、默认颜色头像

### 4.2 账号绑定
- 登录用户自动成为家庭成员（创建/加入家庭时自动创建成员记录关联 userId）
- 手动添加的成员为虚拟成员（userId 为空）
- 绑定方式一：管理员预设手机号，成员用该手机号登录自动绑定
- 绑定方式二：管理员生成6位绑定码（24小时有效），成员输入绑定码关联
- 成员详情页显示绑定状态（已绑定/未绑定虚拟成员）

### 4.3 成员详情页
- 展示成员完整档案信息
- 未绑定成员显示"未绑定"灰色标签
- 虚拟成员在姓名后标注"（虚拟成员）"
- 管理员可见账号绑定区域（预设手机号、生成绑定码）

## 五、「我的」页面整改

### 5.1 卡片式头部
- 左侧：圆形头像（无头像显示相机图标，灰色背景）
- 右侧：姓名 + 角色标签（家庭管理员/家庭成员）+ 性别 + 家庭关系 + 脱敏手机号
- 第二行：身高、体重、目标体重、出生年月（竖线分隔）
- 头像点击：微信头像授权；相册选择入口
- 卡片其他位置点击：进入个人信息档案编辑

### 5.2 个人信息档案编辑
- 字段：姓名、性别、家庭关系、手机号、出生日期、身高、当前体重、目标体重、头像
- 手机号：优先从登录账号获取，4-12位数字校验
- 出生日期：年/月/日三列，支持手动输入 + 📅 选择器，默认当前日期
- 保存后自动在家庭下创建成员记录（如不存在）
- 头像：微信头像授权 + 相册选择

### 5.3 入口与功能
- 我的家庭入口（家庭设置页）
- 数据备份入口
- 退出登录按钮
