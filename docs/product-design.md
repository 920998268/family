# 家庭打卡微信小程序 产品设计文档

## 1. 产品概述

「家庭打卡」是一款面向家庭成员共享使用的日常生活管理小程序，本期交付前端页面与本地数据层（无需后端）。它将家庭里散落各处的日常事务——运动饮食、学习、一日三餐、出行、家庭收支——统一收进一个「打卡 + 计划 + 记账」的入口，让全家在同一处记录、执行和回顾。

本期目标：先完成「简单、快速、可靠」的前端记录与查看流程，验证家庭场景下多模块共用的信息架构是否顺畅。不做复杂分析、智能推荐、社交和云端同步。

## 2. 产品目标

- 家庭成员可快速完成运动、饮食、学习的每日打卡。
- 家庭可制定每日食谱并跟踪执行情况。
- 家庭可制定出行计划并按行程项执行、记录进度。
- 家庭可记录收入与支出并查看汇总。
- 每个成员拥有独立个人信息档案（姓名、性别、出生年月、身高体重、目标体重）。
- 数据以结构化方式本地保存，便于后续扩展统计、分析和云端同步。

## 3. 目标用户

- 有多名成员、希望一起坚持健康习惯、学习计划和家庭事务的普通家庭。
- 对数据分析要求暂时不高，主要需要「记录 + 计划 + 回顾」的家庭用户。

## 4. 功能范围

本期为前端页面设计，共 6 大模块：

### 4.1 运动健身、饮食打卡记录

- 运动打卡：按日期记录训练动作、组数、次数、重量，可关联打卡成员。
- 饮食打卡：按日期与餐次（早餐/午餐/晚餐/加餐）记录食物、份量与可选营养字段，可关联打卡成员。
- 支持新增、编辑、删除当天记录，支持切换日期查看历史。

### 4.2 学习计划打卡记录

- 创建学习计划（标题、学习内容/学科、打卡频率、目标次数、归属成员）。
- 每个计划每天可打卡一次，支持取消打卡。
- 查看今日完成情况与计划列表。

### 4.3 家庭每日食谱制定与执行并记录

- 按日期为每个餐次制定菜品（食材用料、掌勺人、备注）。
- 执行后标记「已执行」，统计每日执行进度。
- 支持编辑、删除与按餐次快速补充。

### 4.4 出行计划制定与执行并记录

- 创建出行计划（标题、目的地、起止日期、预算、参与成员、备注）。
- 计划内含行程明细（时间、活动、备注），逐项标记完成。
- 计划状态：计划中 / 进行中 / 已完成 / 已取消。

### 4.5 家庭支出与收入记录

- 记录收入与支出（金额、分类、日期、记账成员、备注）。
- 分类按类型联动（支出：餐饮/购物/交通/居住/教育/医疗/娱乐/其他；收入：工资/奖金/理财/兼职/礼金/其他）。
- 按本月汇总收入、支出、结余，支持类型筛选与按日期分组浏览。

### 4.6 个人信息

- 个人信息档案：姓名、性别、出生年月、身高、当前体重、目标体重。
- 家庭成员管理：添加/编辑/删除成员（姓名、角色、头像颜色），供打卡与记账关联使用。

## 5. 信息架构与导航

小程序采用 5 个底部 Tab：

| Tab | 页面 | 主要任务 |
| --- | --- | --- |
| 首页 | 家庭看板 | 今日打卡概览、食谱执行进度、进行中出行计划、本月收支小结、六大模块快捷入口 |
| 打卡 | 打卡中心 | 运动/饮食/学习三大打卡模块入口与今日完成进度 |
| 计划 | 计划中心 | 家庭食谱与出行计划的入口、执行进度 |
| 账本 | 家庭账本 | 收支汇总与流水 |
| 我的 | 个人信息 | 个人信息档案、家庭成员、数据备份 |

子页面：饮食打卡、运动打卡、学习打卡、家庭食谱、出行计划列表、出行计划编辑、记账表单、个人信息档案、家庭成员管理、数据备份。

## 6. 核心数据模型

- 个人信息档案：姓名、性别、出生日期、身高、当前体重、目标体重。
- 家庭成员：姓名、角色（父母/子女/长辈/其他）、头像颜色。
- 饮食记录：日期、餐次、食物名称、数量、可选营养字段、打卡成员。
- 训练记录：日期、动作名称、组明细（次数/重量）、打卡成员。
- 学习计划：标题、学习内容、打卡频率、目标次数、归属成员、创建时间。
- 学习打卡：计划、日期、备注、打卡成员。
- 食谱计划：日期、餐次、菜品、食材、掌勺人、是否执行、备注。
- 出行计划：标题、起止日期、目的地、参与成员、预算、状态、备注、行程明细。
- 收支记录：类型（收入/支出）、金额、分类、日期、记账成员、备注。

## 7. 主要使用流程

1. 首次进入：完善个人信息档案，添加家庭成员。
2. 首页查看今日概览，点击模块卡片进入对应页面。
3. 打卡页完成运动、饮食、学习打卡。
4. 计划页制定今日食谱并随餐标记执行；创建出行计划并逐项执行。
5. 账本页记录日常收支并查看本月汇总。
6. 我的页管理个人信息档案与家庭成员，定期导出数据备份。

## 8. 非目标功能

本期明确不包含：

- 云数据库、登录、权限与跨设备同步。
- 食物库、动作库与模板系统。
- 营养分析与训练容量分析。
- 趋势图、统计报表和 AI 建议。
- 消息提醒、社交与排行榜。
